## 发音处理

专用词典按金融场景固定“发卡”为 **fā kǎ**，卡片、银行卡的“卡”读 kǎ；私钥、公钥、密钥的“钥”读 yuè；回调的“调”读 diào；重试的“重”读 chóng。MPC、KYT、API 等缩写使用英文字母读法。

已通过模型调试核对关键术语实际使用的音素与声调。完整语音未出现未知词警告；词典核对不等同于人工听感审校，单独提供术语试听。
