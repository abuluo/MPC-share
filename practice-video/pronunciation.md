# 读音校对与上下文处理

本视频使用本地中文与英文混合语音模型。为避免根据字面误读，合成前使用了专用词典；字幕保留原术语，旁白中的数字尽量写成中文读法。

| 术语 | 读法及上下文 |
| --- | --- |
| 发卡 | fā kǎ，指发行 Visa 等支付卡；不读头饰的 fà qiǎ |
| 开卡、卡片、卡号、银行卡 | 卡统一为 kǎ；银行的“行”为 háng |
| 私钥、公钥、密钥 | 钥读 yuè；区别于“钥匙”的 yào |
| 回调、调度 | 调读 diào；区别于“调试”的 tiáo |
| 重试、重复、重放 | 重读 chóng |
| 处理、处置 | 处读 chǔ |
| MPC、KYT、API、AI、PM | 按英文字母名称逐个读出 |
| TRX、USDT | 按英文字母名称读出；讲稿中的数量使用中文读数 |
| Cobo | /ˈkoʊboʊ/ |
| Elliptic | /ɪˈlɪptɪk/ |
| Sepolia | /səˈpoʊliə/ |
| Nile | /naɪl/ |
| Webhook | /ˈwɛbhʊk/ |
| Auto-Sweep | /ˈɔːtoʊ swiːp/；多数正文直接表述为“自动归集” |

验证方式：对敏感术语生成独立试听，开启模型调试并核对实际使用的音素与声调；完整生成后检查未知词日志及音轨完整性。音素核对不能代替人工听感审校，试听文件一并提供。
